# Narde
Политика конфиденциальности приложения «Нарды»
Дата: 09.11.2026

1. Общие сведения
Приложение «Нарды» — офлайн-игра в длинные нарды. Разработчик: Новиков Владимир. Контакт по вопросам персональных данных: ya.novik26@yandex.ru.

2. Какие данные обрабатываются
2.1. Игровые данные: состояние партии, история ходов, счёт, настройки и сид ГСЧ. Они сохраняются только на устройстве (DataStore) и не передаются разработчику.

2.2. Рекламный идентификатор (GAID), IP-адрес и технические данные, необходимые для показа рекламы и защиты от мошенничества, обрабатываются Yandex Mobile Ads и медиационными партнёрами (VK Ads / myTarget) при наличии согласия на рекламу.

2.3. Приложение не запрашивает ФИО, телефон, email, геолокацию, контакты, фото и не создаёт учётных записей.

3. Цели и правовые основания
3.1. Игровые данные используются для работы игры и сохранения прогресса.

3.2. Рекламные данные используются для показа добровольной рекламы за награду на основании согласия пользователя (ст. 6 Федерального закона № 152-ФЗ). Отказ от рекламы не ограничивает доступ к игре.

3.3. Данные не продаются и не используются для скрытого профилирования.

4. Передача данных
4.1. Рекламные данные передаются Yandex Mobile Ads и медиационным партнёрам в объёме, необходимом для показа рекламы. Их обработка регулируется политикой Яндекса.

4.2. Иным третьим лицам персональные данные не передаются.

5. Сроки хранения и удаление
5.1. Игровые данные хранятся до удаления приложения или очистки данных приложения.

5.2. Рекламные данные — в соответствии с политикой Yandex Mobile Ads.

5.3. Удалить локальные данные можно в настройках Android («Приложения → Нарды → Память → Очистить данные») или удалив приложение. Запрос на удаление данных можно направить на контактный email.

6. Права пользователя
Вы вправе запросить доступ, уточнение или удаление данных, а также отозвать согласие на обработку рекламных данных. Для отзыва согласия используйте настройки приложения/ОС или контактный email.

7. Дети
Приложение не предназначено для детей младше 16 лет. Возрастной рейтинг в магазине — 16+.

8. Изменения
Актуальная версия политики доступна в приложении. При изменениях обновляется дата.
